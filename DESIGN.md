# Design system

## Direction
**Nocturne Systems** — near-black void, warm parchment ink, molten amber registration. Cinematic spatial craft over terminal/cyber tropes.

## Palette
| Token | Value | Role |
| --- | --- | --- |
| `--void` | `#07080c` | Page ground |
| `--ink` | `#f2efe6` | Primary type |
| `--ink-soft` | `#b8b4a8` | Secondary type |
| `--accent` | `#f5a524` | CTA / signal |
| `--void-panel` | `#141820` | Raised surfaces |

## Type
- **Display:** Archivo (500-800)
- **Body:** Sora (400-600)
- **Mono:** JetBrains Mono (labels, years, stack chips)

## Motion
- GSAP ScrollTrigger: horizontal work pan, pinned process stack, manifesto scrub, hero parallax
- Motion: magnetic CTAs, entry curtain, skill / topology reveals
- Custom cursor + scroll progress (desktop)
- R3F: pointer-reactive lattice in Craft (lazy-loaded, paused offscreen)
- Interactive SignalMap topology (SVG graph)

## Radius
Small controls `0.25rem`, panels `0.875rem`, CTAs pill.

## Do not
Purple glow, cream+terracotta, matrix rain, glassmorphism as default, Inter/system stacks, em-dash flourishes, terminal LARP copy.
